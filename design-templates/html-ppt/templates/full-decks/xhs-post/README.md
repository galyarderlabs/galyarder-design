# xhs-post

The RedNote (xhs) 3:4 image-post format, nine cards (810 × 1080). Structure: cover → hook → pain → aha moment → steps 1-3 → result → follow CTA.

Handwritten-sticky-note + sticker + soft-shadow MUJI feel, warm cream background with pink/orange/yellow gradients. Each card carries an `N / 9` page sticker top-right; the closer has hashtag tags.

**Use when:** RedNote / Weibo nine-card carousels / WeChat post hero images / TikTok image posts.
**How to use:** screenshot each `.slide` and export at 810×1080. Press → to walk through.
**Feel:** journal stickers, friend-to-friend "sharing the good stuff" vibe.
