# hermes-cyber-terminal

Black base (`#0a0c10`) + terminal chrome + scanlines + mint-green glow display type + JetBrains Mono throughout for an unmistakable typewriter feel. Inspired by the Hermes-agent record deck's dark `codebox #15151b` plus the head-to-head Hermes-vs-OpenClaw deck — fused into an "honest cyber review" voice.

**Visual traits:** 56px cyber grid + CRT vignette + translucent scanline overlay, window traffic-light chrome, command-line headlines that begin with `$ prompt`, mint-green `#7ed3a4` text-shadow glow, monospace globally, virtual bar chart rendered with stroke-only outlines, blinking cursor, amber/green/red tag hierarchy.

**Use when:** reviewing a developer tool / CLI / agent — show benchmark numbers, traces, diffs; you want the visual voice of an honest technical reviewer immediately; great for long traces or long code listings.

**Source inspiration:** the Hermes-agent record deck and the Hermes-vs-OpenClaw deck.
