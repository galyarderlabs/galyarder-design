Concept ⟷ Example

Left · Concept

A theme is a set of CSS variables. Color, type, radius, and shadow all live inside :root.

  • — Tokens carry meaning, not raw values
  • — base.css renders against tokens
  • — Each theme only edits the variables

Right · Example

:root {
  --bg: #fff;
  --text-1: #0c0d10;
  --accent: #3b6cff;
  --radius: 18px;
}
.card {
  background: var(--bg);
  color: var(--text-1);
  border-radius: var(--radius);
}
