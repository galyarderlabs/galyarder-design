# xhs-white-editorial

White editorial-magazine feel — heavy emphasis blocks and macaron soft-card groups. Inspired by the v2 white-base RedNote post cover (top rainbow bar + huge headline) and the AI testing-and-safety v2 deck (the `.focus` black-on-white emphasis block and macaron soft-card system).

**Visual traits:** pure-white background, top 10-color rainbow bar, huge 80-110px headlines with slight negative tracking, gradient brand text (purple → blue → green → orange → pink), macaron soft cards (soft-purple / pink / blue / green / orange), capsule tag + dot, black-on-white `.focus` emphasis frame, hero quote box with a soft shadow.

**Use when:** you need a white-base content post that doubles as a RedNote image post and a horizontal deck; text-dense, key-point-heavy material that has to grab the keyword instantly; Chinese-first audiences.

**Source inspiration:** the v2 white-base RedNote covers and the AI testing-and-safety v2 deck.
