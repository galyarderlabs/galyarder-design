Trade-offs · An honest look

Pure-HTML decks: where they shine, where they hurt

✓ Pros

  • Zero build — a single file just runs
  • Diffable: Git-friendly, easy to review
  • Programmable: write any animation you like
  • Ship anywhere: URL, PDF, or PNG

✗ Cons

  • No real-time co-editing like Keynote
  • Steeper for non-developers
  • Complex motion still needs JS
  • Some fonts are missing offline
