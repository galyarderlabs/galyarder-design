# dir-key-nav-minimal

8 slides, each on its own solid / gradient mono-background (indigo / cream / crimson / emerald / slate / violet / white / charcoal). Inspired by the original arrow-key edition of the Karpathy knowledge-base deck — eight `t-*` theme classes, one background per slide, arrow-key navigation, minimal editorial feel.

**Visual traits:** unique background color per slide with a single accent, huge 160px headlines with no decorative graphics, 4px stubby accent line divider, arrow-prefixed mono list, bottom-left `← →` keyboard hint and bottom-right page label, full-screen breathing whitespace, JetBrains Mono for numbers / code / keyboard hints, each background carries its own `.dk-accent` color.

**Use when:** you have something to say and not much to show; you want pacing and typography to drive the audience's attention; keynote-style minimalist talks; one idea per slide; public talks / keynotes / launches.

**Source inspiration:** the Karpathy knowledge-base "arrow-key edition" minimal deck.
