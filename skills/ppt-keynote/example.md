# HTML Anything · Product overview

## The problems we solve
- Markdown is easy to write but ugly to share
- Tweet screenshots end up looking awful
- Every platform (WeChat, Zhihu, ...) has its own formatting rules

## Our answer
**Any input → world-class HTML**, powered by your local AI agent

## Three pillars
1. Reuse your already-logged-in local agent (Claude / Cursor / Codex), no API keys
2. Nine world-class template sets (decks, resumes, posters, RedNote, data reports, ...)
3. One-tap copy to WeChat, Twitter, or Zhihu, or export to PNG

## Numbers
- 80 seconds to ship a 31KB deliverable article
- 9 template sets, 8 local-agent integrations
- 0 API keys, 100% reuse of your local session

## Why now
The Claude team has stopped using Markdown and switched everything to HTML. HTML is the reader-facing final form, and AI takes the "verbose" pain away.
