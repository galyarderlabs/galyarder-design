# New-user onboarding flow · HTML Anything

> Whiteboard sticky-note flowchart, 6 nodes, 1 branch

## Flow
1. **Open localhost:3456** — load the main UI in the browser
2. **Auto-detect local agents** — scan PATH and list the CLIs you're already logged into
3. **Pick a template** — 75 templates, organized by use case
4. **Paste content or upload a file** — Markdown, CSV, and Excel are all supported
5. **⌘+Enter to convert** — stream the agent over SSE, the preview updates live
6. **One-tap copy or download** — WeChat, Twitter, Zhihu, PNG, HTML

Branch: if no local agent is found → open the install guide (Claude / Cursor / Codex)
