03 / 08
● COMPARE

Notion vs Obsidian · how AI-friendly

NOTION

Database-native

Great for structured tasks and team collaboration, but —
• AI must go through the API; can't read live full text
• Nested-block structure is complex, token costs are high
• Weak local-first story; doesn't work as long-term memory

OBSIDIAN

Pure Markdown + bidirectional links

Naturally AI-friendly —
• Everything is just files; Claude reads them directly
• Bidirectional links = a graph for free; entity extraction is nearly zero-cost
• Offline, gittable, diffable, revertable

💡 Key insight: AI doesn't need a "smarter database" — it needs a file system it can read on its own.
04 / 08
● SETUP · 4 STEPS

From zero to "AI writes a note" in four steps

1

Install Obsidian + enable the Local REST API plugin

A community plugin, one toggle. It lets external processes read/write your vault.

2

Connect Claude Desktop + the obsidian-mcp server

One MCP config file. Set the token to your vault's API key.

3

Install five obsidian-skills

markdown / bases / canvas / cli / defuddle — so Claude knows how to use Obsidian correctly.

4

Let Claude do one cleanup pass on its own

"Merge duplicate concepts across my last 10 notes and spin up a new MOC" — 90 seconds, done.

05 / 08
● MCP CONFIG

claude_desktop_config.json

// ~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "obsidian": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-obsidian"],
      "env": {
        "OBSIDIAN_API_KEY": "xxxxxxxxxxxxxxxx",
        "OBSIDIAN_HOST": "http://127.0.0.1:27123"
      }
    }
  }
}

Restart Claude Desktop, type /mcp, and you'll see obsidian connected.
