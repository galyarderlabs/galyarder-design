# knowledge-arch-blueprint

Cream-paper (`#F0EAE0`) base + a single rust-red (`#B5392A`) accent + hard black-bordered cards + dashed feedback-loop arrows. Inspired by an architecture-diagram v2 deck — a real "engineering white-paper" feel, like an architectural blueprint.

**Visual traits:** warm cream paper, faint 48px grid for the blueprint feel, sharp 2px black-edged cards, pipeline step-boxes laid out in a row with one hero box raised, top-right rust-red insight callout, oversized 2.5-4px-letterspaced kicker, SVG dashed feedback loop with arrows, Playfair serif big numbers, zero gradients and zero soft shadows — extreme restraint.

**Use when:** explaining a system architecture, data flow, or process breakdown; you want the content to look like a serious technical white paper rather than a marketing post; you need print-ready, README-friendly figures.

**Source inspiration:** the Karpathy knowledge-base architecture-diagram v2 deck.
