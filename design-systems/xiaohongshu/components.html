Single brand red

One red per screen

#ff2442 appears only on primary CTAs, the heart highlight, and the trending tag. Two saturated reds on a single page instantly "degrade" the page from a note into a discount poster.

Soft-black type

Never pure black

Title rgba(0,0,0,.8), body .62, description .45, placeholder .27 — four transparent-black tiers replacing discrete grays. The same overlay works on a white card, a photo, or a drawer.
