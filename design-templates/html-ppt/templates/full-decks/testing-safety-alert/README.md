# testing-safety-alert

White base + red & amber hazard tones + striped danger trim + bold red strikes and pills. Inspired by an AI testing-and-safety v2 deck — its `.focus` black-on-white blocks, hero quote box, and high-contrast voice — but pushed all the way into "warning / risk control / incident report" territory.

**Visual traits:** top 45° red-and-black hazard band, bottom secondary stripe, red diagonal `strike-through` headlines for negation, three-tier color cards (green / amber / red) for L1/L2/L3, alert-box with a circular indicator dot, policy-yaml dark code block with a red left border and `bad`-keyword highlighting, red/green checkbox checklist, Q1 incident stacked bar chart.

**Use when:** explaining safety / risk control / incident retros / red-teaming / AI pre-launch reviews / policy-as-code; whenever the audience needs to feel "this is serious, don't skim".

**Source inspiration:** the AI testing-and-safety v2 deck.
