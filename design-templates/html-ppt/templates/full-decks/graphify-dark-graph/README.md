# graphify-dark-graph

Deep-night dark base + force-directed knowledge-graph overlay + warm glassmorphism cards. Inspired by the original Graphify deck — a `#06060c` gradient background, drifting orb halos, glass cards (warm / blue / green / purple variants), and rainbow-text headlines.

**Visual traits:** `#06060c → #0e1020` diagonal gradient, three 400-520px blur orbs slowly drifting, cover SVG force-directed graph as background, rainbow-shift gradient headlines, JetBrains Mono `.cmd-glow` command line, glassmorphism cards with top highlight and subtle inner shadow, warm accent palette (`#e8a87c` amber / `#7ed3a4` mint / `#7eb8da` mist-blue / `#b8a4d6` lilac).

**Use when:** introducing a developer tool, a CLI product, a knowledge-graph or data-viz project; whenever you want a live demo to feel "AI-native, sci-fi, and warm".

**Source inspiration:** the Graphify dark-mode graph deck.

**Path:** `templates/full-decks/graphify-dark-graph/index.html`
